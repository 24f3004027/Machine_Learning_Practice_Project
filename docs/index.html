Architecture & Innovations

⚡

Regex Physical Spec Parser

Extracted exact numerical horsepower, operating tonnage, and bucket yardage from unstructured string descriptions using targeted multi-pattern regex parsers.

⏳

Temporal & Depreciation Ratios

Engineered non-linear interaction features including Machine Age at Sale, Operating Hours per Year, and Machine Age / Model Age ratios.

🧠

Log-Space Multi-Seed Ensemble

Blended predictions across 5 random seeds using weighted log-space averaging: Deep XGBoost (45%), LightGBM (35%), and CatBoost (20%).

📐

Jensen's Variance Adjustment

Applied empirical post-processing multiplier (1.001300) to restore log-transform variance and eliminate Jensen's Inequality bias.
